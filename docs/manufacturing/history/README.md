# History

Reports, manifests and deployment logs from earlier releases (V68–V70.0.x), kept for
reference. Nothing here is used by the build, the tests or the deploy.

- `compose.printer-v119*.yml`: host-specific overrides that pinned locally built images from the
  V119 printer rollout. The label printer is configured through `GEAR_LABEL_PRINTER_*` in `.env`.
- `deployment-reports/`: output of the old remote deploy script.
