TRUCK LOG PRINT AGENTS - V4R7 / WATCHER W3
Updated 2026-10-29. Guard service and embedded V4R7 installer unchanged.

W3 addresses three review findings:
1. Slow printer submissions/PDF extraction no longer block the eight-route
   capture scanner. Accepted PDFs enter a durable bounded FIFO, then an
   independent worker verifies/prints them in order. Queue-full warnings,
   before-print hash checks and renderer cancellation support safe recovery.
2. Restart safety records provenance and quarantines pre-existing staging
   files. READY entries may resume; ACTIVE/interrupted work never reprints
   automatically. Pending LIVE captures lose print authorization when their
   route is OFF/TEST or the configured printer changes.
3. The Windows service installer protects an existing credential with an
   exact SYSTEM/Administrators-only ACL before adjusting nonsecret state
   permissions. Recursive ACL resets were removed, including during upgrades.

UPDATE
Run 02-SAP-Queue-Watcher\INSTALL-WATCHER-SERVICE.cmd as Administrator to
upgrade the SAP watcher only. It keeps the installed watcher.ini unless
-ReplaceConfig is requested. Existing INIs use max_pending_captures = 500
by default. Preserve all state/PDF directories and inspect NeedsReview
following startup. Do not reinstall the unchanged guard service.
